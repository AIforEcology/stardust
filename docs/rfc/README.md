# RFCs

Proposals for open standards that come out of the Stardust work. Each RFC is published as a draft for public comment before it's revised.

| RFC | Title | Status | Comment period |
| --- | --- | --- | --- |
| [0001](0001-unified-telemetry.md) | Unified Telemetry Specification for Real-Time AI Inference Energy Accounting (v0.1) | Public comment | 60 days |

RFC 0001 is derived from the Stardust Telemetry Specification T1.5 ([`../stardust-telemetry-spec-T1.5.docx`](../stardust-telemetry-spec-T1.5.docx)), which is a subset of master spec v1.6 ([`../stardust-spec-v1.6.docx`](../stardust-spec-v1.6.docx)).

## How to comment

Anyone can comment. Use whichever of these fits:

- **Open an issue** with the `rfc-0001` label for questions, objections or gaps. Quote the section number (for example `§4` or `§6`) so the comment can be traced.
- **Open a pull request** with the `rfc-0001` label for concrete wording changes to [`0001-unified-telemetry.md`](0001-unified-telemetry.md). Explain the reason for the change in the PR description.
- For general discussion, reply on the pinned issue **RFC 0001 public comment (60 days)**.

The comment period runs 60 days from publication. When it closes, the Technical Steering Committee will publish how each substantive comment was resolved, then issue v0.2 (see §8 of the RFC).
